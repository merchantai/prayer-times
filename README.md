# Prayer Times

An Android application that displays Islamic prayer times, Hijri dates, Qibla compass, and provides widgets for quick access. 

## Features
- Real-time prayer times and next prayer countdown
- Qibla compass
- Hijri calendar date
- Widgets (Horizontal and Large) for homescreen
- Light and Dark mode support
- Background alarms for prayer times and Ayyam-e-Beed
